## 🧠 Deep Learning
Designing and training neural networks for real-world problems — from
**CNNs** for image tasks to **RNNs/LSTMs** for sequential data. I focus on
the full cycle: data pipelines, architecture design, training, evaluation,
and optimization using **TensorFlow**, **Keras**, and **PyTorch**.

## ⚙️ MLOps
Taking models from notebook to production. I build reproducible workflows
with **Docker**, expose models through **FastAPI** endpoints, and apply
**CI/CD** practices to ship scalable, maintainable ML systems — not
experiments that die in a `.ipynb`.

## 🤖 AI Engineering
Building practical AI applications powered by **LLMs** and **RAG systems**.
I combine retrieval, prompt engineering, and orchestration (**LangChain**,
**Hugging Face**) to deliver AI products that answer real business questions.

## 🔧 Git & Version Control
Clean, professional workflows: feature branches, meaningful commits, and
collaborative development on **GitHub** — engineering discipline applied
to every project.
